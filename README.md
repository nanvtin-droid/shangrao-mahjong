# 饶有牌趣 · 上饶麻将研习社

面向电脑和手机的上饶麻将学习、练习与四人模拟对弈网站。

## 已实现

- 10节分级课程：认牌、摸打、组合、翻宝、吃碰杠、自摸、七对、十三烂、九幺和地方规则差异。
- 18道分级练习：即时反馈、解析、重试和学习成就。
- 玩家与3个机器人对弈：三档决策，真实洗牌发牌、摸打、吃碰明暗加杠、杠后补牌、自摸判胡、流局、教学积分与出牌提示。
- 牌局暂停/继续、本机存档；四家独立牌河与全部弃牌弹窗；机器人不读其他玩家暗手。
- 34种统一的真实质感生图麻将牌面与绿色牌背。教程、练习、实战共用图集，不以代码绘制牌面符号。
- 设备中文旁白，支持暂停、继续、停止；《流水》真人古琴演奏背景音乐，支持暂停后续播和音量调节。
- Sites账号登录。课程、练习和完成的牌局按账号写入D1，跨设备同步；当前未结束的牌局只在本机保存。
- 响应式手机界面、键盘焦点、对话框焦点约束、减少动态效果偏好。

## 规则版本

本站明确采用“茶馆教学规则 v1”。本桌只允许自摸及庄家起手胡；支持平胡、碰碰胡、七对、十三烂、七星十三烂、九幺及宝牌替代。基础教学分依次为1、3、4、4、8、6，无宝额外加1，只取最高满足牌型。

地方术语和差异完整列在规则页，但飞宝奖罚、接宝、地胡、抢杠、七星九幺额外加分、清一色叠加、豪华七对叠加、连庄及杠分未在教学桌启用。这不是全市统一的官方规则或任一平台的完整复刻，无金钱输赢。

## 本地运行

需要 Node.js 22.13+。依赖已安装。

```sh
npm run dev
```

默认预览 http://127.0.0.1:5173 。本地登录使用Sites预览自带测试身份；正式部署使用平台身份验证，不能将本地测试身份用于生产授权。

```sh
node node_modules/typescript/bin/tsc --noEmit
node --experimental-strip-types --test tests/mahjong.test.ts
npm run build
```

D1结构见 `db/schema.ts`，迁移见 `drizzle/`。后续修改结构先运行 `npm run db:generate`，不可更改已发布迁移。

## 验证

21项引擎测试通过，包括24局固定随机种子完整模拟、136张实体牌守恒、6种胡牌、吃碰杠优先级、补牌、自摸、玩家响应等待、机器人不读对方暗手、无效牌数与提示边界。

浏览器检查覆盖：首页与课程、练习错误反馈、真人音乐播放/暂停、旁白播放/暂停/继续、出牌、机器人轮转、碰牌移出牌河、四家牌河、390像素手机布局。本地未登录进度接口返回401，登录后数据库读取正常。真实iOS/Android设备的语音取决于系统中文语音包。

## 文件

- `components/teahouse.tsx`：页面和交互。
- `components/tile.tsx`：生图牌面图集渲染。
- `lib/mahjong.ts`：纯函数对弈引擎。
- `lib/content.ts`：课程与题库。
- `lib/audio.ts`：真人音乐播放器和可暂停旁白。
- `app/api/progress/route.ts`：按登录身份隔离的学习进度接口。
- `IMAGE-PROMPT.md`：生图方式与全部提示词。
- `MUSIC-CREDITS.md`：演奏者、来源和录音许可。

网站默认按Sites私有访问发布，手机使用同一账号登录。其他人的访问范围需要在Sites中明确调整。
